# Brand assets

Dashboard brand uses outlined SVG logos (not a live font):

| Theme | File |
|-------|------|
| Light | `Assets/brand-logo-light.svg` (dark ink + `#435CEC` lucent) |
| Dark | `Assets/brand-logo-dark.svg` (white ink + `#435CEC` lucent) |

PNG `@3x` copies are kept as optional fallbacks. Font files here are only needed if you later embed a licensed face for other UI text.
